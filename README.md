# Сбор-разбор · CubeSat

Учебно-методическое пособие по сборке, настройке и программированию сборно-разборного макета спутника типа CubeSat.

## Содержание

- **Сборка** (`assembly.html`) — комплект, инструменты, пошаговый монтаж и контроль перед включением.
- **Программный код** (`code.html`) — опрос датчика BMP280 по I²C и структура телеметрии.
- **Практика** (`practice.html`) — 6 лабораторных работ и таблица измерений.
- **Диагностика** (`diag.html`) — типичные неисправности, контрольные вопросы и структура отчёта.

## Публикация сайта (GitHub Pages)

Сайт — статический и размещается на GitHub Pages из ветки `main` из корня репозитория.

Чтобы включить публикацию:

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
3. Укажите ветку **`main`** и папку **`/ (root)`**, нажмите **Save**.
4. Готовый сайт будет доступен по адресу: `https://nasvi89.github.io/Sbor-razbor/`.

Файл `server.js` намеренно исключён — локальный сервер Node.js на GitHub Pages не выполняется.
